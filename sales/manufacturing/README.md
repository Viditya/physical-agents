Each week's top 5 (by ARR) are logged below with a link to that company's profile page, which holds the fuller writeup. A company's profile page reflects its *most recent* appearance in a top-5 — if it wins again in a later week, the profile is updated in place rather than duplicated (same convention as `demo-results/`, which always shows the latest finding, not a version history).
