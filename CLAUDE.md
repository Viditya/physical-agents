# Claude Code compatibility

`AGENTS.md` is the canonical repository guidance for every coding agent,
including Claude Code and GitHub Copilot. Read it before making any change.

For role-specific work, use the corresponding definition in `.claude/agents/`.
Those roles refer back to the canonical guidance to avoid diverging Copilot and
Claude Code workflows.

Load `.claude/skills/physical-agent-experiment/SKILL.md` before a new
physical-agent experiment.
